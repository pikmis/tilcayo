КАК ЗАПУСТИТЬ «Толстого Тилкайо» на компьютере

1. Распакуйте архив целиком: правый клик по zip -> «Извлечь всё».
2. Откройте получившуюся папку и запустите Tilcayo\Tilcayo.exe

ВАЖНО
Папку Tilcayo нужно распаковать целиком. Если вытащить один
Tilcayo.exe на рабочий стол, игра не запустится: рядом должны
лежать папки app и runtime — это сама игра и встроенная Java.

Управление
  Пробел / W / ↑ / левая кнопка мыши — прыжок
  A / D / ← / →                        — рывок в сторону
  Esc                                  — пауза
  F11                                  — полноэкранный режим

Прогресс сохраняется автоматически и лежит рядом с игрой.
Чтобы перенести сохранение на другой компьютер, скопируйте
папку Tilcayo целиком.

Windows может показать «Windows защитила ваш компьютер» —
это обычное предупреждение для программ без цифровой подписи.
Нажмите «Подробнее» -> «Выполнить в любом случае».
